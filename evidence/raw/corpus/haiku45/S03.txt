A hash collision occurs when two different inputs produce the same hash value from a hash function. Since hash functions map a potentially infinite input space to a finite output space, collisions are mathematically inevitable. When they happen in a hash table, multiple keys may try to occupy the same bucket, degrading lookup performance. Good hash functions minimize collisions through distribution properties, while collision resolution strategies like chaining or open addressing help mitigate the problem. Understanding collision behavior is crucial for tuning hash table capacity and choosing appropriate load factors.
